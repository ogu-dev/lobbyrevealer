## TOS

In order to ensure every license is bound to a unique player, some information about your computer is stored by my licensing. Hardware information about your PC is stored and encrypted in transit for security purposes to ensure that 2 people do not use the same license/slot. To clarify, no information stored is uniquely identifying (such as passwords, emails, riot tags), and therefore can not be pinpointed to a specific person. In some cases, such as the slotted version, your discord id is stored however this is done only with the cooperation and consent of both the user and the seller.
